HỒ SƠ THI CÔNG GIAN SOCRATIC VISION BOARD · BẢN CHO CORELDRAW
STEM Carnival · AIROC 2026 · Nhà thi đấu Phú Thọ · lắp 28/11, trưng bày 29/11

1. Mở file: CorelDRAW > File > Import (Ctrl+I) hoặc Open file .pdf.
   Toàn bộ chữ đã chuyển thành nét (curves): không cần cài font, không bị nhảy font.
2. Tỉ lệ 1:1, đơn vị mm. Khổ trang = kích thước thành phẩm + tràn lề (ghi trong 00_BANG-KE-THI-CONG.pdf).
   Ví dụ S15a = 3 000 × 620 mm + tràn 3 mm mỗi phía.
3. File *_DUONG-CAT.pdf: đường cắt CNC màu magenta (#EC008C, nét 0,6 mm). Đặt chồng lên file in cùng tên, căn góc trên-trái.
4. Ảnh chụp (S02, S03) là ảnh bitmap nhúng sẵn. Xin ảnh gốc độ phân giải cao từ nhóm trước khi in khổ lớn.
5. Bản vẽ kích thước: 01_BAN-VE-KICH-THUOC.pdf (A3). Màu: hệ RGB, chuyển CMYK theo máy in, giữ xanh tươi (gần C80 M55 Y0 K0) và cam (gần C0 M65 Y80 K0).
6. Xem nhanh: thư mục xem-truoc/*.png.
7. Màn 1 483,2 × 896,9 × 104 mm. Ô khoét S01 lệch 105 mm về phía vách phải để lưng màn không chạm vách BTC (hở 27 mm vách sau, 37 mm vách phải). Đo lại màn và vách thực tế trước khi cắt.

CHUYỂN TOÀN BỘ SANG .CDR (1 lần, tự động)
- File ChuyenPDFsangCDR.bas là macro cho CorelDRAW X5 trở lên.
- CorelDRAW > Tools > Macros > Macro Editor (Alt+F11) > File > Import File… > chọn ChuyenPDFsangCDR.bas.
- Tools > Macros > Run Macro > ChuyenPDFsangCDR.ChuyenTatCa > dán đường dẫn thư mục hồ sơ đã giải nén > OK.
- Mỗi PDF (kể cả thư mục con) được mở đúng khổ 1:1 mm và lưu thành .cdr cùng tên, cùng chỗ.
- Nếu Corel hiện hộp "Import PDF" cho từng file: chọn Import text as: Curves > OK (chữ vốn đã là nét).
- Muốn làm tay từng file: File > Open (Ctrl+O) file .pdf > File > Save As > CorelDRAW (*.cdr).

DÙNG CORELDRAW BẢN WEB (CorelDRAW.app, bản dùng thử)
- Đăng nhập CorelDRAW.app > File > Open > chọn file .pdf trong gói (hoặc file .svg trong gói SVG) > chữ đã là nét nên mở ra đúng ngay.
- Kiểm tra khổ trang ở thanh thuộc tính (đơn vị mm) khớp bảng kê, rồi File > Save As / Download > chọn CorelDRAW (.cdr).
- Bản web không chạy macro .bas: làm từng file, mỗi file khoảng 1 phút.
